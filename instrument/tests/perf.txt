# CYMA-1 performance (spec §3.13-3.14, §6.9, §8.2). The engine's worst cases, three times:
#   1. the device's default configuration (mode budget 96), the worst without the bow; then "metrics": the device
#      figure (est_max <= 2,900)
#   2. the host's (budget 128), the same worst case, long enough (> 17 s) that the UI's last 1024 frame times are
#      all of it, animating; then "perf" (native UI: median <= 350 us, p99 <= 700 us with 2000 grains) and
#      "metrics" (est_max <= 3,500)
#   3. four bowed voices (the bow's maximum) on top, host config; then "metrics" again: reported, not gated (spec
#      §3.14 counts the bow junction on top of the no-bow worst, under the device's governor)
# The no-bow worst: eight struck voices held and leaned on with DRIVE, vibrato and the LFO melting the shape (every
# slot refreshing its coefficients each sub-block), SURFACE strikes over them (the ninth slot), rain on every key.
# est_max is the engine's model of native instructions a sample (spec §3.13), not a measurement; the UI times are
# this machine's wall clock, meaningful only on an otherwise quiet machine. tools/golden.py reads the lines:
#   perf ui_med_us ui_p99_us ui_max_us render_med_us render_max_us est_max
#   instrument/build/host/cyma-1_host instrument/tests/perf.txt OUTDIR
master 4096
