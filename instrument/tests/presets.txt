# CYMA-1 presets (spec §4.4, §8.2, §8.3.2): each of the 24 factory presets, two renders:
#   presetNN_c4.wav  C4 (key 7) at velocity 100, held 1.5 s (bowed and rained presets sound only while held),
#                    then 1.5 s of ring: no NaN, peak <= -0.3 dBFS, peak >= -30 dBFS, and the level of the
#                    strike for the +-4 dB match (an advisory figure: M4/M7 tune LEVEL against it).
#   presetNN_g7.wav  G5 (key 26) at OCT+2, velocity 127: the top of the range, where modes crowd Nyquist. tools/
#                    golden.py measures the energy above 0.45 fs there: <= -100 dB, <= -80 dB with DRIVE (16-18).
#                    presetNN_g7f.wav is its float twin (wavf, the fx output just before the one quantisation): the
#                    gate reads that one, since an undithered int24 render of a quiet note shows only the 24-bit
#                    container's floor above 0.45 fs (golden.py reports the int24 figure beside it).
# Each render has 200 ms of lead-in, so golden.py can tell the strike from the last preset's room still ringing.
# Between presets REC (DAMP) chokes the plate; the room tail of the last preset may still be fading.
#   instrument/build/host/cyma-1_host instrument/tests/presets.txt OUTDIR
