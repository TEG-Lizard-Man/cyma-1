# CYMA-1 silence (spec §3.5, §3.10.7, §8.2): play, then leave it alone for 60 s. The last 5 s must be exact
# zeros: modes cull below 1e-12 of their peak, the FDN's denormal guard is DC that the DC blocker removes, and
# the quantiser has no dither, so digital silence is digital zero. The boot preset (SINGING BOWL, a 16 s bronze
# ring at C4, a 4 s room), as someone would leave it. tools/golden.py checks the WAV too, sample by sample.
#   instrument/build/host/cyma-1_host instrument/tests/silence.txt OUTDIR
master 4096
wait 1700
tour 0
peakreset
wav24 out:silence.wav
wait 200
# a short phrase, softly and loudly, with a lean
key 7 down 80
wait 400
key 7 up
key 11 down 100
wait 300
key 14 down 110
wait 300
key 11 up
key 14 down 110 80
wait 800
key 14 up
key 2 down 127
key 9 down 127
wait 250
key 2 up
key 9 up
wait 500
key 19 down 90
wait 200
key 19 up
# ---- 60 s idle; the last 5 s must be exact zeros
wait 55000
peakreset
#@mark silence_tail
wait 5000
expect peakq 0
wav24stop
expect nan 0
expect voices 0
metrics
